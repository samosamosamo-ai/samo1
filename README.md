# Cars Website

A simple static website about cars.

## Usage

Open `index.html` in your web browser to view the website.

## Features

- Home section with introduction
- About section
- Car gallery with sample cars
- Contact form with basic JavaScript alert

## Files

- `index.html`: Main HTML file
- `styles.css`: CSS styles
- `script.js`: JavaScript for form submission

## Troubleshooting

If the website doesn't load properly, ensure all files are in the same directory and open `index.html` directly in a browser.
